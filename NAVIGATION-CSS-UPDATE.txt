CAMPBELLWEB STICKY DROPDOWN NAVIGATION UPDATE
==============================================

Files changed
-------------
- index.html: uses one accessible Menu button for desktop and mobile and loads script.js.
- style.css: makes the header sticky and applies the shared responsive dropdown layout.
- script.js: controls the shared dropdown and retains the active website interactions.

Desktop and mobile behaviour
----------------------------
- The full navigation header stays sticky at the top on desktop and mobile.
- A compact gold Menu button appears below the centred logo at every screen size.
- All nine links remain hidden until the Menu button is opened.
- Desktop displays the open links in a compact three-column panel.
- Mobile displays the open links in one column.
- The menu closes after selecting a link, clicking outside, pressing Escape, or changing the screen width.

Publishing
----------
Upload all files and folders in this package together. Do not omit script.js.
