CAMPBELLWEB — ADDING VERIFIED TESTIMONIALS AND LIVE PROJECT LINKS

TESTIMONIALS
1. Open index.html.
2. Find: id="testimonials" hidden
3. Replace the three placeholder reviews, client names and business names with real, verified feedback.
4. Remove the word hidden from the opening section tag.

LIVE PROJECT LINKS
The CampbellWeb project already links to the live website. Other projects display “Live link available on request” because no verified URLs were supplied.
To add a URL, replace that note inside the relevant project-actions block with:
<a class="project-btn project-btn-primary" href="YOUR-LIVE-URL" target="_blank" rel="noopener noreferrer"><i class="fa-solid fa-arrow-up-right-from-square"></i> View Live Website</a>

Never publish a client testimonial or project URL without the client’s permission.
