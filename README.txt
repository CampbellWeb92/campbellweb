CAMPBELLWEB ENQUIRY FORM FIX

1. Replace the current index.html on your website with the index.html in this folder.
2. Upload thank-you.html to the same main folder as index.html.
3. Keep your existing style.css and images folder unchanged.
4. Submit one test enquiry from the live website.
5. Check infocampbellweb@gmail.com (including Spam/Junk) for the FormSubmit activation email and click the activation/confirmation link.
6. Submit a second test enquiry. It should arrive in the inbox and redirect the visitor to thank-you.html.

What changed:
- Removed the AJAX code that could block the form's normal submission.
- The form now posts directly to FormSubmit using its existing action URL.
- Added a redirect to a branded thank-you page after successful submission.
